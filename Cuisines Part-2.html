Family Fonts

Whenever we want to change the size of font we will use the code "font-size"

Whenever we want to change the style of font we will use the code "font-style"

Whenever we want to change the weight of font we will use the code "font-weight"

Whenever we want to change the Font Family of font we will use the code "font-family"

Whenever we want to change the Transformation of the Font we will use "text-transform"
